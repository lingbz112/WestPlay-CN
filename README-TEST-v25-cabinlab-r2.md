# WestPlay QQ Music v25：Cabin SoundLab r2

这一版针对两个实际听感问题：

1. 转头时高音像贴在 A 柱上，整个声音随头转向单侧移动。
2. 低音仍经过左右扬声器 HRTF，听起来有方向性。

## 固定方向车舱反射

`Cabin IR` 和 `Full Cabin` 现在在驾驶舱中放置 8 个方向固定的离散反射点：

- 左右侧窗
- 挡风玻璃左右
- 顶棚
- 仪表台
- 后墙左右

每个反射点都有独立的延迟、高通、表面吸收低通、增益和 HRTF 空间位置。它们随车舱位置固定，而不是随头部朝向移动；所以向右转头时，A 柱直射高音会变化，但玻璃、顶棚和后墙的反射仍保留空间参照。

原来的短卷积扩散层和可调混响仍保留。`Full Cabin` 会同时使用车舱 EQ、固定方向早期反射、短扩散层和长混响。

## 低音管理

新增标准 car-audio bass management：

- 90 Hz 以下先合成为单声道。
- 低频直接进入总线，不再经过左右扬声器 Panner/HRTF。
- 90 Hz 以上继续使用左右声道的扬声器定位。
- 低频仍经过 Cabin EQ、压缩、总限幅和车外衰减。

本地 WebView2 60 Hz 测试结果：

```text
playing from a: "[0.6084,0.6238,-4.47]"
playing from b: "[0.6173,0.6329,-4.47]"
playing from a: "[0.6108,0.6262,-4.47]"
```

左右耳低频电平接近，且没有因绕过 HRTF 而静音。

## A/B 模式

设置位置：`设置 → 声音 → 驾驶室音色`

- `Reference`：没有车舱 EQ、IR 或混响，但保留 90 Hz bass management。
- `Cabin EQ`：车舱频响与温和压缩，无方向反射和混响。
- `Cabin IR`：固定方向早期反射与短扩散层，无车舱 EQ 和长混响。
- `Full Cabin`：全部叠加。
