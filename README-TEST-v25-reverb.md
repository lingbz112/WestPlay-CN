# WestPlay QQ Music v25：驾驶室混响

这是带驾驶室空间混响的测试包。

## 实现方式

保留车型扬声器位置、HRTF 声场和现有均衡器，在扬声器混合之后增加共享混响发送：

- 程序化生成短脉冲响应，不附带大型音频文件。
- 包含早期反射和阻尼扩散尾音。
- 预延迟、尾音长度和高频衰减由驾驶室大小决定。
- 混响发送使用 180 Hz 高通，避免重低音在尾音里堆积成浑浊的轰鸣。
- 高频衰减比低频快，避免高音过多时混响发刺。
- 干声保持完整，混响强度只控制湿声比例。
- 驾驶室大小滑动时对脉冲响应生成做短暂防抖，避免拖动滑块产生连续重建。

## 设置位置

`设置 → 声音 → 驾驶室混响`

提供：

- 开关。
- 紧凑日间驾驶室。
- 标准卧铺驾驶室。
- 大型 / 长驾驶室。
- 空间大小 0–100%。
- 混响强度 0–100%。

默认：开启，空间 55%，强度 32%。

## 推荐调法

- 小车/日间驾驶室：紧凑预设，通常 25–40% 强度。
- 普通卧铺：标准预设，30–38% 强度。
- XXL、长驾驶室：大型预设，38–48% 强度。
- 重低音强的音乐：不要把强度靠高补偿；保持 30–40%，利用混响的 180 Hz 高通避免低频发浑。
- 高音偏亮：缩短尾音或把空间往小调；混响本身会对高频做更快衰减。
- 如果原曲本身混响很重，优先降低混响强度，再调整 EQ。
