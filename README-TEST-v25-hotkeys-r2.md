# WestPlay QQ Music v25：全局媒体快捷键 r2

这是快捷键版本的第二版，修复测试包中车机 UI 未同步的问题。

## 修复

- 上一曲/下一曲不再被旧车机脚本误当成“音量减”。
- 新版完整 `ui` 目录已放入测试包，不只替换 EXE。
- 播放/暂停、上一曲、下一曲默认使用键盘的媒体键，并在游戏前台全局生效。
- 用户已经自定义过的播放/暂停绑定会保留；只有旧默认 Alt+2 会迁移为媒体播放/暂停键。

## 安装

1. 完全退出 ETS2 和 WestPlay。
2. 运行 `install-plugin.cmd`。
3. 直接运行 `westplay.exe`。
4. 在“控制 → 按键绑定”检查“播放/暂停、上一曲、下一曲”。

桥接版本为 25，主程序和插件 DLL 必须一起使用本包。
